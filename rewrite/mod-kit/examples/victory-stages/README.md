# 可选示例：三阶段条件与替换结算界面

第一征服任意选国：开局安装第4回合胜利门槛，第2回合改为第4回合且持有1000金钱，第3回合弹窗确认后再改为坚持到第4回合；同时达到第8回合失败时失败优先。多次完整替换规则和待选阶段可存档恢复。示例用于验证接口，实际作品应更换自己的目标与回合。

`rewrite/victory-screen.json` 内嵌420×256新布局，重命名全部数据控件与三个命令按钮；使用原有勋章/星级/按钮/将领资源。胜利和失败共用布局、按结果显示继续或重开。可追加 `defeatLayout` 单独替换失败界面，或追加 `"*"` 全局界面。其余剧本默认保持原布局。

完整字段与多阶段注意事项见[接口指南](../../docs/porting/VICTORY_MODDING.md)。需包含本接口的新宿主，旧0.2.6不支持。

用工具包执行 `pack <本目录的工作副本> --id=victory-stages --name=多阶段胜利示例`，随后import/export为 `.ew4mod`。不要覆盖内置data，也不要覆盖自己已有extension.json的技能等注册项；合并字段后重新pack。
