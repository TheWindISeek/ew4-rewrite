# 可选示例：叛乱后选择扮演、修改目标与分支结局

覆盖包源码，须使用包含事件控制接口的新宿主，旧0.2.6不支持。完整字段见[接口指南](../../docs/porting/SCENARIO_CONTROL.md)。

第一征服开局，当 `conquest1.unit.10` 仍位于493格时弹出选择。两个按钮都会将驻军及493格交给地方共和国；join切换控制权并把目标改为存续至第5回合，stay继续扮演原国家。选择法国可模拟进攻方转投当地叛军，选择驻军原所属国可模拟本国分离。第5回合先展示结局叙述，再由确认按钮提交胜利及 `republic.independence` 分支。

叛军独立指定俄式招募变体、旗帜和绿色领土；原国改由AI控制，按正常顺序轮到新国。仅转交列出的单格，不自动转交城市辖区。换剧本须替换驻军及格号。

用工具包执行 `pack <此目录> --id=scenario-control --name=角色切换示例`，再 import / export 为 `.ew4mod`。机器绑定的生成清单不随源码附带；一次只启用一个Mod。
