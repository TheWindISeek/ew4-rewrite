# 势力事件示例

包含创建新势力、不创建的选择分支，以及随后改国号、国土颜色和旗帜的事件链。使用内置第一征服、俄国兵种和现有旗帜，不要求继承开局势力。需使用包含 2026-10-21 势力接口增补的宿主，旧 0.2.6 发行包不含此接口。

复制本例 rewrite/ 到作者覆盖目录，用新版 Ew4.ModTool pack 打包并在独立账户导入。新开第一征服，从第 3 回合起，指定驻军仍在原地时出现地方起义弹窗；承认则创建 civil.rebels，维持原状则不创建。后续事件改为独立共和国、红色领土及法国旗，与玩家保持中立。

为使例子可直接加载，选用了内置开局的 conquest1.unit.10 和地块 493；unit_at 条件避免转交已经死亡或不在原地的部队。正式剧本应按目标城市/驻军条件修改触发时机及转交对象。本例不自动添加到原游戏。立即试验分支时，可在作者副本把 round.value 改为 1。

改为占城直接创建时，将 condition 替换为 cells_owned，把 recognize 按钮的 effects 移到事件自身 effects，并移除 popup。创建不要求固定回合或等待时间。

独立 PNG 旗帜、Mod 新增 unitVariant、自定义招募授权、复国及存档规则见[完整势力接口](../../docs/porting/SCENARIO_FACTIONS.md)。
