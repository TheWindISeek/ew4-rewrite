# 0.2.0 / 2026-10-20

本轮发布同时更新仓库源码、ARM64 APK 和 Windows x64 独立 Web 服务包。两端使用同一份最新后端，包含开放规则 API 1：动态技能/特性、将领技能槽及布局、离线 Lua、JSON/BTL VICT 胜负规则，以及 JURI 手工辖区。接口字段、事件和函数说明见 `mod-kit/docs/porting/RULE_EXTENSIONS.md`。

Mod 管理支持选择文件后自动识别标识和名称，仍可编辑再导入；删除必须确认，内置内容不可删除，删除安装内容会保留存档和导入源文件。原版技能图标回退及暂停、商店按钮等显示修复同时包含。

东亚底图已并入 `data`，与 Europe、America 同级，包含158×136网格、278处城市/据点、272处设施、54处桥梁或渡口及71处双语地理标注。城市名和地理标注的语言独立切换。本轮不添加正式东亚战役或征服菜单。政治归属与辖区由未来剧本确定。

原格式 BIN 只保存地形；`data/original/eastasia.map.json` 另保存无归属的城市等级、设施和桥梁模板，`data/client/maps/eastasia` 同时提供落格表。制作剧本时按该模板写入 BTL 设施记录。地图制作配置保存在 `maps/eastasia_rewrite`，生成暂存与旧 v1–v5 文件不再在仓库重复保存，历史仍可从 Git 查询。

验证：完整核心回归0错误；客户端859项；原Mod77项、自动识别21项、删除29项、扩展包18项、CLI9项、扩展浏览器20项；内置东亚引擎7809项；独立Web资源、启动与存读档9146项。东亚桌面1280×720与手机390×844实际截图和画布像素通过，无页面异常。APK检查全部运行资源、前端、ARM64运行时和本次构建程序集，另核验签名。浏览器结果及最终包SHA-256见发布校验记录。

Web包解压后运行 `Ew4.Web.exe --urls http://127.0.0.1:5191`，浏览器访问该地址。无需安装.NET；默认账户、存档及Mod写入包内`saves`目录，可用`--save-root`另选持久目录。此包为本地服务加浏览器界面，不是纯静态网页。

APK版本0.2.0、versionCode 2，最低Android 8.0，ARM64。当前使用开发调试证书签名，未进行Android设备运行验收。与不同签名的旧安装包不能直接覆盖；保留旧数据再处理安装。旧开发快照的内容指纹可能不同，本轮未宣称所有历史测试存档兼容。AI主动技能规划仍不在API 1范围，原APK的SO/DEX不执行。
