# EW4 rewrite 本地游戏预览

运行目录独立包含后端和显示资源，无需引用原包工作区。

开放技能/特性/胜负规则见[API 1指南](docs/porting/RULE_EXTENSIONS.md)，包含包内文件、Lua、动态技能位置、BTL VICT和函数对照。旧Android安装包需升级到包含此接口的版本才能执行扩展；当前源码编译通过不等于旧包自动更新。

| 目录/文件 | 用途 |
| --- | --- |
| `Ew4.Web` 与相关DLL | 本地游戏宿主、规则及离线Mod转换模块 |
| `wwwroot/` | 浏览器界面程序，非Mod覆盖目录 |
| `data/` | 基础原资源、转换规则与显示资源；子目录README解释各层 |
| `saves/` | 默认账户和战局，支持 `--save-root` 另行指定 |
| `saves/content-mods/` | 默认Mod安装与启用选择，支持 `--mod-root` 指定 |

启动时可用 `--urls http://127.0.0.1:5184` 选择本机地址。源码开发可指定 `--root`，发布运行通常使用自身data；不同实例请用不同端口和save-root。

主菜单左下角 **Mod** 支持本地APK/资源ZIP/`.ew4mod`导入、校验和启用。Android源码提供相同入口，并调用系统文件选择器，可在手机独立导入。切回原版恢复基础资源；Mod的规则指纹和标识决定独立存档目录，不覆盖原版账户或战局。

已安装的 Mod 可点击“删除”，核对弹窗中的名称后确认；取消或 Esc 不会删除。删除当前启用的 Mod 会切回原版。仅移除安装内容，原始导入文件及存档保留，重新导入同一内容可继续读档。内置原版不可删除，导入期间暂不可删除。

选择文件后自动读取 `.ew4mod` 清单标识/名称或 APK 包名/应用标签，缺失时使用文件名；可修改后再点击“导入”。APK 证书不作为 Mod 名称来源，同一签名可能用于多个不同 Mod。

内置东亚底图含278处城市/据点、生产设施、地形和河流桥梁，提供独立的城市名/地理标注中英文开关。当前不附正式东亚战役或征服，供后续剧本引用。

原APK中的SO/DEX不执行，新原生机制不能靠资源替换自动恢复。兼容已验证的原格式BTL、地图、图集、位图字库、动画及已有规则；未支持的技能ID会报错。制作与命令行导出说明在另行交付的离线Mod工具包README中。

本目录也附有[配置字段索引](docs/CONFIG_REFERENCE.md)、[源码函数索引](docs/SOURCE_INDEX.md)及[具体排错表](docs/TROUBLESHOOTING.md)。开发源码路径供定位，不代表发布目录需要另找这些源码才能运行。

替换基础data或在已安装哈希目录内直接手改会破坏校验。请从作者原资源重新导入，或在覆盖包里修改后重新pack并导入。只换贴图保留同标识与逻辑内容时可沿用存档；规则和剧本更新会保留旧档并启用新逻辑目录。
