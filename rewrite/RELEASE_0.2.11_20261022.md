# 0.2.11 / 2026-10-22

本版恢复原版部队详情、战场将领信息及任命界面，并修复详情面板裁切。

- 部队详情使用原版布局与资源，恢复将领信息入口和真实费用。可查看己方、敌方、剧本及酒馆将领的实际战局信息和装备，返回后保留原部队。
- 顶部三个方框统一高度，左右卡片同宽；修复右侧头像越过底边、中间底行图标和数字显示不全。原部队说明下方预留独立技能/效果标签区。
- 任命界面恢复原版六列两行、名额及逐将领“出征”确认。局外指挥部继续保留60槽、筛选及标签管理。
- 战场撤回键右侧增加同款方形定位键，优先寻找未移动且未攻击的部队，再寻找仍有行动的部队；定位保持缩放、不消耗行动。
- Android 统一避让系统栏、刘海、手势、瀑布屏及圆角，并增加边缘留白；修复小视口弹窗确认键越界。

## 下载与运行

Windows 10/11 x64：完整解压 Web ZIP 后双击 `Start-Web.cmd`，无需安装 .NET。升级时保留原 `saves/`，也可通过 `--save-root` 指定旧目录，避免多个服务共用同一存档目录。

APK：ARM64，Android 8.0 及以上，versionName 0.2.11、versionCode 13，沿用原开发证书，可覆盖同签名旧版。过旧 WebView 仍需更新。

附件提供 Web ZIP、APK、`SHA256SUMS.txt` 与记录源码提交的 `release-manifest.json`，不包含玩家档案、存档或签名密钥。
