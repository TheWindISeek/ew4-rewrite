# 0.2.12 / 2026-10-22

上将界面适配新版指挥部，修复出征按钮对齐，并为 Mod 开放派遣名额配置。

- 上将名册支持鼠标左右拖动和触摸滑动，按每列先上后下排列，已保存标签的将领置顶并显示标签。保留将领信息和出征操作，不添加星级筛选或标签编辑按钮。
- 出征按钮与所属将领槽水平居中，横竖屏均可完整显示。
- 内置剧本的上将数量限制保持原值。Mod API 2 新增 `deploymentLimits` 接口，可按全局或指定剧本设置名额；支持 0 禁用、null 不限，省略配置沿用原值。作者模板默认空表，完整说明位于 `mod-kit/examples/deployment-limits/`。
- 延续 0.2.11 的原版部队详情资源、齐平三框、将领及装备信息返回、技能/效果标签预留区域与 Android 安全边距修复。

## 下载与运行

Windows 10/11 x64：完整解压 Web ZIP 后双击 `Start-Web.cmd`，无需安装 .NET。升级时保留原 `saves/`，也可通过 `--save-root` 指定旧目录，避免多个服务共用同一存档目录。

APK：ARM64，Android 8.0 及以上，versionName 0.2.12、versionCode 14，沿用原开发证书，可覆盖同签名旧版。过旧 WebView 仍需更新。

附件提供 Web ZIP、APK、`SHA256SUMS.txt` 与记录源码提交的 `release-manifest.json`，不包含玩家档案、存档或签名密钥。
