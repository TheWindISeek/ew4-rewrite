# 东亚底图资源

第三张地图eastasia，158×136网格，21488格，278处城市。保留此前275城ID和落点，本轮在西昆仑山口补塔什库尔干1级据点、越南顺化以北补河静2级城市；按后续红圈在西侧两片山地间另补萨尔哈德1级据点，塔什库尔干保留。此前8处增补见`map_additions.json`。

城市初始1/2/3/4/6/7级，上海、东京、大阪开局7级；独立设施包括56工厂、47马厩、50港口和119农田。陆上设施分散填充城间空地，菲律宾工厂、马厩及两处农田分布于岛内中南部；全图稀疏区域另补31处节点。港口按岸线使用四种朝向，并核对实际可见海面；阿帕里港北移，那霸港移至[121,97]海格并保持向右伸出。4520条有向河边与54处通行节点同步写入逻辑和贴图：长江/金沙江15处、黄河13处、其他26处，其中29座桥、25处木质通桥外观概化的渡口路线。按截图减少长江中游5处、黄河10处密集渡口，保留关键节点及连续无桥河段；修复马哈纳迪河源数据在希拉库德段的断口。现代地图`eastasia.map.json`保留城市、设施及通桥标记。配置按民国时期经济地理概化，正式剧本按`year`/`kind`调整桥梁和渡口；设施参照城市不代表固定管辖关系。

底图只保留基础城市名称。征服条目可用`citynames="conquest7.names.xml"`指定同目录XML名称覆盖表，未覆盖城市沿用底图名；`original/conquest7.names.xml`为空表示例。修改后重新封装/导入并启动剧本，格式及城市ID见完整说明。

海洋前景沿用原版七种波纹，固定随机种子分散布置723处，密度为连通外海海格的10%，避开可见岸线、建筑及文字。46个英文自然地理标注包含37个陆地区域及9个海域，沿用原版地图字形和文字层；原有文字库条目及字形图集保持原样。配置源为`maps/eastasia_rewrite/cartography_plan.json`，显示细节和位置见同目录`cartography.json`及`geographic_labels.json`。

导入同级`../eastasia-map.ew4mod`即可在当前rewrite基础版本启用。完整文件说明、重建方式及验证结果见`../../../maps/eastasia_rewrite/README.md`。

本图不预设政治归属或管辖区。管辖区由具体征服剧本的时期边界确定；附带conquest7仅作检查，所有城市无归属，两支原版部队仅用于验证显示、选格和移动。
