# 0.2.10 / 2026-10-22

本版汇总 0.2.9 之后的指挥部、显示和 Mod 接口更新，Web 与 Android 共用实现。

- 指挥部增加全选及军事学院原图的一至三星区筛选，每区 20 位、共 60 槽；已标记将领优先，其余按三星、二星、一星排序，每列先上后下，再向右排列。两排区域支持鼠标拖动及手指横向滑动，无可见滚动条，滑动不触发将领点击。
- 公主、商店右侧新增“标签”按钮，点击进入赋予标签模式；点击将领添加左下角三角标记，再点取消。按钮变为独立文字“确认”，点击后一次保存、退出模式并把已标记将领排在前面。选择过程中不跳位，返回可放弃未保存的选择，详情页不含标签编辑。
- Mod 接口新增将领击杀专属台词及条件规则，可按目标将领/兵种、剧本、回合和血量筛选；没有配置时保持原版随机行为。
- API 2 物品/装备绑定复用技能 JSON 与离线 Lua，支持主动、被动及消耗品效果、实例状态/冷却、原效果保留或替换，作者指南和示例随 Web 包提供。
- 全局国家配置支持长文本/中文 ID、别名和独立旗帜/兵模；CNTR v1 保存 BTL 的完整国家引用，ModTool 提供导出、应用和移除命令。修正包括神罗在内的兵模映射。
- 战场行动旗帜和血量颜色按原版规则修正；设定增加“跳过回合快进”“过回合跟随行动部队”两个独立开关，默认关闭。
- Windows Mod 导入在验证后的目录改名遇到短暂占用时进行有上限的重试，改善偶发导入失败。

## 下载与运行

Windows 10/11 x64：完整解压 `web-win-x64.zip` 后双击 `Start-Web.cmd`，无需安装 .NET。默认端口 5191，占用后顺延。升级时保留原 `saves/`，也可用 `--save-root` 指向原目录，避免多个服务共用同一存档目录。

APK：ARM64，Android 8.0 及以上，versionName 0.2.10、versionCode 12，沿用原开发证书，可覆盖同签名旧版。过旧 WebView 仍需更新；本次不含 Android 设备运行验收。

附件提供 Web ZIP、APK、`SHA256SUMS.txt` 和记录源码提交号的 `release-manifest.json`，不包含玩家档案、存档或签名密钥。
