# 0.2.4 / 2026-10-20

界面文字改为完整离线字库：Noto Serif SC Regular 400为主，Jigmo三份字库覆盖生僻汉字，GNU Unifont与Upper补充其他文字。六份WOFF2不裁剪字符，合计30,512,720字节，cmap合并覆盖192,816个码位；已移除不再使用的25.9MB旧字体。UTF-8是编码，实际字形范围以`data/client/fonts/coverage.json`为准，不承诺所有未来Unicode字符或私用字。

DOM与Canvas使用相同内置字体链，加载完成后才测量和绘制，不引用系统字体。原版与Mod仅提供文字内容，不沿用FNT/PNG字形样式。城市名保持白色填充、黑色描边；未覆盖字符在Canvas中显示替代符并记录码位。字体来源、许可、配置文件、函数名和重建步骤见字体README及Mod移植指南。

Web包完整解压后双击`Start-Web.cmd`，自动启动本地服务并打开浏览器，无须安装.NET或Python。保留服务窗口，退出时按Ctrl+C；默认端口5191，占用则顺延。账户、存档和已安装Mod默认保存在包内`saves`目录，可用`--save-root`指定原来的持久目录。升级前保留旧包中的存档，不把旧前端或字体复制覆盖进新包。

APK版本0.2.4、versionCode 6，Android 8.0及以上、ARM64。本包同时包含此前Android启动/JNI、资源异常处理、原图标、沉浸全屏、刘海安全区、系统返回键与触摸高亮修复。沿用开发签名证书；不同签名包不能覆盖安装。此版完成编译、资源与程序集逐项核验、签名和对齐检查；本轮未在Android设备运行，不把先前0.2.3的模拟器结果当成本版设备验收。

本轮验证：六份字库压缩前后cmap不丢字；原版和本地六个APK的XML/INI文本审计无缺字；浏览器42项、10张桌面/手机截图通过，异常及缺失资源均为0。通过浏览器实际字体信息确认常用/生僻中文及多语种探针均来自自带字库，城市填充/描边、商店居中和国家长名均检查。发布附件提供Web ZIP、ARM64 APK、源码提交号和SHA-256清单。

延续0.2.0的规则API 1、JURI/VICT、离线Mod导入与隔离、内置东亚底图。AI主动技能规划及原APK的SO/DEX执行不在支持范围内；既有Mod的原生专属机制不因此自动兼容。完整基础功能说明见`RELEASE_20261020.md`。
