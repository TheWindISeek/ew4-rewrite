# 颓垣饿鸠 · 独立制作工程

基于 rewrite 的近代中国战争 Mod，当前为将领及八个征服的可运行试制版。目录名仅作内部工作标识，不是正式名称。

正式名称：**颓垣饿鸠**，2026-10-20由用户确定。化用鲁迅《题三义塔》“败井颓垣剩饿鸠”，并非原诗连续四字。现有目录、包ID与导出文件名保留为内部兼容标识；后续构建使用正式展示名称，已有导出包不因本次定名自动更新。

阵营配置待重做：用户指出rewrite允许多阵营，当前试制却仍用两至三个交战阵营及统一中立组，未达到多方角力要求。已只读核对引擎，支持更多阵营号；不同交战阵营默认敌对，复杂同盟与观望不能只靠编号表达。重整原则与逐年方向见[多阵营记录](../mingguo-mod-plan/DIPLOMACY.md)。本轮仅修正策划，尚未改写游戏配置或生成新包。

## 使用

已有独立预览：`http://127.0.0.1:5206`。启动其他端口可运行 `./Start.ps1 -Port 5207`。

- `dist/republic-working-title-0.1.0.ew4mod`：可导入支持东亚底图、JURI v1、VICT 扩展的当前 rewrite；本次只安装到这里的私有运行目录。
- `source/generals.json`：正式制作源名册，219人，三星38、二星148、一星33。沿用208人初稿，补10位英国军官及孙渡；ID从1001开始，人物转属沿用同一ID。
- `source/conquests.json`：8个开局的日期、势力、阵营、省域及城市覆盖、初始将领和敌后部署点。
- `source/geography.json`：境外及殖民据点的共享地区配置。
- `source/historical-regions.geojson`：旧省区网格级草绘；不能作为已考证历史省界。
- `build/overlay/`：生成的独立资源覆盖层；不直接编辑它，修改制作源后重新生成。
- `build/scenarios/`：逐剧本展开后的城市归属、部署、逐格国家归属及辖区中心表。
- `reports/`：名册、势力预览图、实际开局/招募/存档/辖区检查及隔离报告。

重新生成：在本目录执行 `./Build.ps1`；已有独立运行副本时可用 `./Build.ps1 -NoRuntimeCopy`。只从既有引擎与底图读取和复制，不在原工程下编译。重新生成后重启本目录的预览服务以载入新包。

## 隔离边界

所有作者源、编译缓存、引擎副本、Mods、账户、存档、日志和导出包都在本目录。没有导入其他运行中的预览，也没有修改原始APK、`apk_work/`、`rewrite/`或原有安装目录。构建前后比较这三个受保护范围的完整文件路径、长度和修改时间；实际消耗的地图制作参考另做SHA256检查。结果见 `reports/isolation.json`。不自动回滚外部变化。

## 本版已经生效

- 1915、1924、1926、1927、1930、1937、1944、1946，共8个东亚征服，独立两页菜单；原版战役暂不展示。
- 219人进入实际将领定义和招募池；一二三星招募区映射到引擎评分2、5、8，已分别抽取检查。
- 每个已开放势力至少两名开局将领；中立背景不强行开放。开局部署限制部分人物存亡与出场年份，名单并未全部完成任职考证。
- 英国殖民军在早期按沿江合作体系编入相关阵营，保留独立国家、城市与资源；1946法军与滇军同在国民政府一方。该外交配置是用户指定的势力范围玩法，不冒充对应年份已发生的参战史实。
- 每个BTL真正写入JURI v1。先按行政区域参考和该年势力配置生成逐格版图，再按同势力、同区域分配中心；缺少候选时才退到同势力最近中心。海格及港口为-1，城市/工厂/马厩中心指向自身；存档重载保留同一数组。
- 农村敌后点用于1944与1946的抽象部署，没有把所有根据地伪造成完整城市占领区。

## 需要继续制作

1. 历史边界与城市归属。目前使用省域规则、代表城市和少量旧省区草绘；并非精确战线。现代省界仅作稳定区域参考，不能据此宣称恢复了1915—1946行政区划。城市以下真实县界尚未取得，当前辖区在这些地方按就近补齐。
2. 早期法军。1915、1924、1930、1937保留接滇系的同盟目标，但适龄双人任职未核实，暂中立。1926、1927滇系与法属地区目前均中立。1944维希殖民当局也保留中立；1946开放勒克莱尔、瓦吕伊。
3. 兵力与将领部署。当前为代表性守备和战区抽象，并非史实战斗序列；多数将领初放总部周边，需逐人移到实际战区。属性仅是步兵/骑兵/炮兵/后勤模板，没有正式技能方案。
4. 军旗、将领头像、现代兵种与标题美术。旗帜使用颜色识别占位，头像使用引擎的无人物占位；不把拿破仑等旧头像当成中国人物。兵种仍复用基础规则与表现。
5. 动态北京政变、宁汉合流、东北军介入、抗战投降移交等尚未制作。当前阵营关系固定，中立暂不可选；招募池跨年代，年代限制只用于开局部署。
6. 正式胜利与平衡。当前采用明确的试制目标：消灭敌对阵营，或到第30回合且玩家达到5000金钱/1200工业/2000粮食；180回合上限。该目标只用于跑通玩法，不是最终各方历史任务。
7. 战役保持独立策划状态，本版没有制作185关战役。

## 行政参考来源

`source/china-provinces-modern.geojson` 下载自阿里云 DataV 的现代中国省界参考：<https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json>，2026-10-20获取。SHA256与逐格命中数量记录于 `reports/administrative-boundaries.json`。热河、察哈尔、绥远、西康另有可编辑草绘覆盖；境外和无法匹配的区域按原城市归档组就近补齐。未把这份现代数据标成历史资料。
