## 当前实现

主菜单左下角 Mod 入口打开管理器，可导入 APK、资源 ZIP 或 `.ew4mod`，查看转换进度和兼容提示，选择启用后重载。一次启用一个内容包；原版可以随时切回。电脑使用本地文件上传，Android 使用系统文件选择器和应用私有缓存；两端共用 Ew4.Mods 转换、验证与安装逻辑，不依赖联网或 Python。

原格式转换覆盖 UI/头像/旗帜/兵种贴图、位图字体、地图索引及底图、BTL 剧本、将领 XML、文字、动画和音频。支持 PNG、ETC1 PKM、RGBA4444 PVR、BILE v3、YSAE 和已验证的 BTL v2。新增征服剧本自动加入分页；原版仍保留六个原征服和第二页空位。

只使用资源和已实现规则，不运行导入 APK 中的 SO/DEX。原生代码新增技能、不同地图格式和新命令不自动兼容；原技能 ID 0～39 可转换，未知 ID 会报错。原兵种等级导入范围0～2。报告记录原生库哈希及限制，不声称能恢复任意改版的原生扩展。

内容包按哈希独立安装，校验成功才提交；失败保留当前启用内容。不同 Mod 及不同逻辑版本分别保存账户/战局，纯贴图更新保留同一逻辑存档目录；内置版存储位置不变。导入不自动启用。路径、重复项、哈希、基础版本、资源引用、剧本启动和图片解码均校验，XML 禁止外部实体。

## 攻击随机边界核查（只读）

用户询问下限是否失效。`Ew4.Core/Combat.cs` Rolls 当前为 `max(RNG(max+1), min)`，正常非负且 min<=max 时，每次基础攻击均在闭区间内，主动攻击和反击共用。但分布偏向下限，不是区间均匀抽样；min>max 没有配置拒绝，退化为 min，可能超过所填上限。下限技能可能使相等的两个端点发生同样情况。底层 RNG 只有15位输出，大区间也有可达性问题。

最终伤害经过攻击次数、士气/星级、攻防和倍率，仅保底1，不直接受单次基础攻击区间限制。已逆向的 ARM64 原路径同样有 max 钳位（见 GAMEPLAY.md），不能据此认定所有原版/改版都存在用户描述的下限失效。本轮没有修改随机分布或战斗规则；未将这次代码核查表述为边界专项测试。
