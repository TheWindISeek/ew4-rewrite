## 恢复

本地恢复材料位于 `duplicates/local-resources-20261022/`，已加入 Git 忽略规则，不随源码或发行包上传：

- `blobs.zip`：唯一文件内容；不是原目录结构的普通 ZIP。
- `manifest.json`：每个原路径、大小、修改时间和 SHA-256。
- `restore.py`：按原路径恢复，已有文件内容不同则停止，避免覆盖改动。
- `cleanup-summary.json`：清理结果及归档摘要。
- `cleanup-audit.zip`：完整清理清单、检查结果和本轮执行脚本，保留审计及恢复依据。

在项目根目录按需恢复，例如：

```powershell
python duplicates/local-resources-20261022/restore.py --prefix build/release-0.2.9-20261021
```

省略 `--prefix` 恢复全部文件；加 `--verify-only` 仅校验归档。历史记录仍保留当时路径，重用旧安装包、旧构建或测试导入资源前，先恢复对应路径。
