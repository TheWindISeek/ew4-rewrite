# 原版将领技能 JSON 参数覆盖

## 交付范围

按用户选定的“倍率、概率、折扣、成长数值外置”层级完成：29 种原版技能、36 个参数。增加 `extension.json` 的 `legacySkillParameters` 文件引用，使用 API 2、参数文件 schema 1；不改技能的机制、触发时机、随机数取样顺序、单精度运算和取整。布尔型机制仍保留原有实现。

作者入口：`rewrite/mod-kit/examples/legacy-skill-parameters/`，其中 `rewrite/definitions/legacy-skill-parameters.json` 是完整原版数值模板，README 给出 29 种技能的 ID、字段、范围、示例及打包方法。参数可按技能和字段部分覆盖；未提供的值回退原版。已有扩展包只需合并入口字段，无须新增完整技能定义或 Lua。

## 实现与兼容

- `Ew4.Core/LegacySkillParameters.cs`：不可变参数表、逐技能字段及数值校验；伤害/经验/经济倍率、移动/攻击 bonus、费用/触发 percent、教学 gain/maximum。未知 ID/字段、重复键、null、非整数及越界值拒绝加载。
- `ExtensionLoader.Load`：显式注册参数文件并纳入现有扩展版本摘要，API 1 拒绝新字段；旧 API 2 引擎也需更新才能识别此字段。
- `ClientContent` 将同一组参数交给 runtime/combat catalog；战斗、经验奖励、原军队恢复、将领任命、名册派遣、酒馆、AI 生产及四种单项费用共享。教学增量/上限由原整编规则执行。
- 同 ID 完整扩展定义仍关闭原版技能；原参数不会与扩展效果重复叠加。经验装备仍优先于经验技能；专家/大师优先关系保持原样。
- 无参数配置时 nullable 规则字段不纳入旧场景指纹，原版与旧 Mod 的账户/场景绑定保持不变。开启参数配置后按现有 Mod 规则版本隔离账户和存档；不会把旧局面强制套用新参数。
- 参数变更需要重新 pack/import，不是热加载。技能说明仍来自文字表，作者调整参数时需同步文案。
