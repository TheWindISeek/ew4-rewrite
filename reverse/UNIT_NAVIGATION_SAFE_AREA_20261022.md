2026-10-22。首次交付按用户要求仅保留源码和本地预览；随后在部队详情修复任务中明确授权统一打包发布0.2.11，详见 `rewrite/RELEASE_0.2.11_20261022.md`。本次重新构建最终方形图标与小屏修复，旧中间APK仍不可交付。发行包定位153项检查、资源/程序集及同证书签名/对齐通过，真机待验。

## 行为

- 战场撤回键右侧新增定位键，73×74 原撤回图底板、相同方形灰底及透明边距，白色准星；按钮与撤回键同为 37×37 逻辑尺寸，间隔随战场缩放。
- 只处理当前人类玩家自己的部队：先循环未移动、未攻击的单位，再循环只剩移动或攻击未用的单位。未攻击但当前射程内没有目标也保留；不能移动的要塞按未用攻击处理。排除死亡、施工、混乱、行动已耗尽及其他势力单位。
- 每个层级各记已定位单位；已找到的未行动单位移动后仍能进入第二层。两层遍历完毕后重启循环；回合/玩家变化、新局及读档重置。
- 定位只选择单位、更新操作栏和镜头，保留缩放，不执行旧选择的移动/攻击，不消耗行动。重复点击加锁；对白、事件、电脑回合和已结束状态禁用。

## 屏幕适配

`Ew4.Android/MainActivity.cs` 在原生 FrameLayout 上统一设置安全边距，WebView、画布和 DOM 采用同一缩小后的坐标系：

- API 30+ 合并系统栏稳定占位、刘海、系统手势/底部手势区和瀑布屏边距。
- API 26–29 回退到 stable insets，并按系统能力补充刘海、手势区。
- API 31+ 按屏幕圆角半径计算内缩；所有设备另加 12dp 留白，补偿厂商不报告的边缘遮挡。
- 系统栏显隐保持布局稳定，横屏方向/尺寸变化时重新请求 insets。
- `.modal` 使用明确的可收缩网格行列，修复未缩放高度大于安全视口时网格撑高、设置确认键被挤到下边界外的问题。
