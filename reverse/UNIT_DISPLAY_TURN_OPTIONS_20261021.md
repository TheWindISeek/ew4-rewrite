# 部队显示与过回合选项

日期：2026-10-21。用户确认增加两个独立设置；快进设置只改变点击“跳过”后的表现，不自动触发跳过。修改共享 Web 前端，Android 使用同一套前端；本轮未生成新 APK 或进行手机运行验收。

## 原版依据

- `native/decompiled/00050900.c` 调用 `0x80c18` 取得玩家国家，只有所属国匹配时才调用 `0x4fb38` 决定旗帜是否飘动，再传给 `0x62cb8`。敌国和盟国部队使用静态旗面。
- `0x4fb38` 的条件为：`(movement > 0 && morale != -3) || (construction < 1 && !acted && targetFlag)`。当前客户端已有 `remainingMovement/morale/constructionTurns/acted/canAttack`，其中 `canAttack` 表示存在合法攻击目标。保留原版“移动耗尽但未攻击、仍有目标时可以继续飘动”的例外，不把 `acted` 或移动动画是否结束作为唯一条件。
- 保留原旗帜锚点 `(-27,-45)`、四帧/100ms、独立图片静态旗和既有港口设施规则。渲染调度也使用同一个旗帜条件，静止敌军不再单独触发连续重绘。
- `native/decompiled/00060958.c`、`00060b68.c` 是地图/面板血量圆标绘制。按当前/最大血量分上下半段计算整数颜色，传递 ABGR；满血 RGB `(0,255,128)`，半血 `(255,255,0)`，零血 `(255,0,0)`。保留原有阵营底板和圆弧长度、透明度，新增原版颜色计算，并钳位非法比例。
- `tools/reverse/capture_unit_display.py` 执行原 ARM64 库，图形接口被截获；64 组旗帜判断、1239 组血量颜色（最大血量 100/137/999，逐整数取样）共 1303 项通过。库 SHA256、函数地址及原始样本保存于 `reports/unit_display_vectors.json`。该证据不等于 Android 像素验收。

## 两个设置

- **跳过回合快进**：默认关闭，保存在 `ew4.settings.skipTurnFast`。关闭时点击“跳过”仍逐步执行 AI，保留基础部队移动（65ms/格）和地块变化，省略战斗、受击、死亡、招募、喊话演出及步间等待。开启后点击“跳过”走既有 `ai_batch`，关闭中间战场绘制，不播放镜头、移动、战斗或音效；右下角国旗和国家名称仍按势力交接更新，保留浏览器绘制机会。
- **过回合跟随行动部队**：默认关闭，保存在 `ew4.settings.followAi`。普通行动和基础跳过都跟踪当前移动部队、攻击者或新招募部队，沿现有移动路径采样位置，沿用 `Ew4Camera.constrain` 边界，不更改缩放。跟踪时锁定拖动和缩放；关闭设置、回到任意人类席位、剧情暂停或 AI 循环结束后释放。完全快进优先，停止中间镜头追踪。
- 两个开关独立，不因开启设置自动结束玩家回合或自动点击跳过。旧设置缺字段时默认关闭，只有布尔 true 被识别为开启。设置滚动布局沿用现有样式。
- 点击跳过会取消当前移动/战斗/到达/死亡、特效音效和演出等待；后续动作按选中的模式执行。既有剧情、选项、胜负和存档边界保持。
